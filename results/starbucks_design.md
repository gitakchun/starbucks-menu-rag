# 스타벅스 메뉴·알레르기 Q&A 설계

## 1. 문제 정의

스타벅스 고객이 메뉴의 카페인·영양·알레르기 표시와 리워드·사이렌 오더의 기본 정보를 자연어로 물으면 공식 공개 자료를 근거로 안내합니다. 근거가 불충분한 질문에는 답을 만들지 않습니다.

예상 질문은 "우유 못 먹는데 뭐 마셔요?", "카페인 적은 거 있어요?", "별 적립 왜 안 돼요?"와 같이 매장에서 들을 법한 표현입니다.

## 2. 사용자와 범위

| 사용자 | 지원하는 질문 |
|---|---|
| 메뉴를 고르는 고객 | 공개된 메뉴 설명, Tall 기준 영양·카페인 수치 |
| 알레르기 우려 고객 | 공식 상세 페이지에 명시된 알레르기 유발요인 |
| 앱·리워드 이용 고객 | 자료에 확인된 리워드 결제 기본 안내와 사이렌 오더 개요 |

2026-10-06 수집 기준으로 음료 198개 목록 URL과 푸드 118개 목록 URL에서 상품 코드를 중복 제거해 메뉴 316개를 수집했습니다. 공개 FAQ의 고객지원 8개 카테고리에서 질문·답변 422건을 수집해 총 738개 지식 레코드를 구성했습니다. 실제 수집 시점의 목록이므로 이후 변경될 수 있습니다.

## 3. 출처와 데이터

`data/starbucks_knowledge.jsonl`은 수집기 `src/collect_starbucks_data.py`가 공식 공개 페이지에서 생성하는 JSONL입니다. 각 레코드에 상품 코드/FAQ ID, 카테고리, 원본 URL, 수집 시각을 기록합니다.

| 자료 | 공식 수집 경로 | 포함한 내용 |
|---|---|---|
| 음료 카탈로그 | `/upload/json/menu/{category_code}.js`, `/menu/drink_view.do?product_cd=...` | 10개 음료 분류, 상품 상세 JSON-LD, 규격·영양·카페인·알레르기 표시 |
| 푸드 카탈로그 | `/upload/json/menu/{category_code}.js`, `/menu/food_view.do?product_cd=...` | 7개 푸드 분류, 상품 상세 JSON-LD와 알레르기 표시 |
| 고객지원 FAQ | `/voc/getVocCauseCodeList.do`, `/voc/getFaqList.do` | 회원·결제·메뉴·매장·딜리버스 등 8개 카테고리의 질문과 답변 |

robots.txt가 허용하는 공식 페이지와 JSON 응답만 초당 4회 이하의 요청 간격으로 수집합니다. 데이터 갱신 시 수집일·출처 URL을 유지하고 파싱 누락을 확인해야 합니다.

## 4. 안전 원칙

- 공식 페이지에 특정 알레르기 유발요인이 명시된 경우에만 그 표기를 전달합니다.
- 이번 수집에서는 알레르기 유발요인이 기재된 메뉴 120개와 상세 페이지에 표시가 없는 메뉴 196개를 구분했습니다. 미표시를 "알레르기 성분 없음"으로 해석하지 않습니다.
- 교차접촉, 상세 원재료, 대체유의 안전성, 개인별 알레르기 반응은 이 문서로 판단하지 않습니다. 이 경우 매장 파트너 확인을 안내합니다.
- 유당 불내증과 우유 알레르기를 같은 것으로 취급하거나 섭취 가능 여부를 의료적으로 권고하지 않습니다.
- 수치에는 메뉴 규격을 함께 말합니다. 다른 사이즈·옵션의 수치를 추정하지 않습니다.
- 공개 FAQ 목록에서 질문 제목만 확인되는 상세 규정과 개인별 미적립 원인은 추측하지 않습니다.

## 5. RAG 흐름

```text
starbucks_knowledge.jsonl
  -> JSONL records -> LangChain Documents
  -> RecursiveCharacterTextSplitter (chunk_size=450, overlap=40)
  -> text-embedding-3-small
  -> 738 records / 780 chunks -> FAISS
  -> Dense / Hybrid / Reranker Retriever (Top-3)
  -> 근거 한정 및 알레르기 안전 Prompt
  -> gpt-4o-mini
```

현재 검색 구조와 모델 비교는 기존 실습 코드를 재사용합니다. 수집기 실행에는 OpenAI API 키가 필요하지 않으며, 임베딩과 생성 평가는 기존 OpenAI API 키가 필요합니다.
